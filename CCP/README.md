# 《计算机网络》综合课程设计

## 任务要求
1. 从下面选 1 道题完成。
2. 提交源程序和报告。

## 选题列表

1. TCP 客户端-服务器聊天程序
> 做一个一对一的字符界面聊天工具。服务器监听指定端口；客户端连上后，双方可以互发文字，输入 `quit` 等指令即可断开。还要处理基本的连接异常，保证消息可靠传输。

2. UDP 广播消息发送与接收
> 写一个 UDP 广播程序：一台主机向局域网的指定端口广播时间或自定义文字，多台主机绑定该端口，收到后显示消息。借这个实验理解 UDP 的无连接和广播特性。

3. TCP 文件传输工具
> 让客户端向服务器传一个文本文件。客户端读取本地文件，经 TCP 套接字分段发送；服务器收齐后写入新文件，再检查两边的文件大小是否一致。

4. 多线程 TCP 聊天室
> 在基础聊天程序上加入群聊：服务器同时连接多个客户端，收到一人的消息后转发给其余在线用户。每个连接用线程处理，避免一个客户端卡住所有人。

5. 模拟 HTTP 简单请求与响应
> 写一个能处理 `GET` 请求的小型 HTTP 服务器。浏览器访问 `http://服务器IP:端口/文件名` 时，服务器读取对应的本地文本文件，返回状态码、响应头和文件内容；文件不存在就返回 `404 Not Found`。

6. 基于 UDP 的可靠文件传输（模拟停等协议）
> 用 UDP 模拟停等协议，可靠地传文件。发送端每发一段就等接收端确认（ACK），超时则重发；接收端校验数据，正确才回复 ACK，否则丢弃该段。

7. 局域网设备扫描工具
> 扫描指定 IP 段，找出存活的主机和开放的常见端口，如 `80`、`443`、`22`。可以用 ICMP 回声请求判断主机是否在线，再尝试 TCP 连接检查端口。

8. 简易即时通讯协议设计与实现
> 自己设计一套简单的应用层协议，比如规定消息类型、发送方 ID、数据长度和内容。用 TCP 在客户端和服务器之间传消息，并正确解析、显示文字和预设字符表情。

9. 也可以分析 `ping`、`tracert` 抓包，或自拟相关题目。
